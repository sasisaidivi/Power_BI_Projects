# 📂 Projects Included

## 🚚 1. Contest Logistics Dashboard

### 📌 Project Overview

This project focuses on **Logistics and Supply Chain Analytics** using the **OTIF (On-Time In-Full)** performance metric.

OTIF is an important supply chain KPI used to measure a supplier's ability to deliver products:

* On time
* Within the prescribed delivery window
* In the complete quantity ordered

The dashboard helps stakeholders monitor delivery performance and identify opportunities to improve logistics operations.

### 🎯 Key Objectives

* Track important logistics KPIs
* Analyze OTIF performance over time
* Monitor order delivery status
* Identify high-performing areas and segments
* Discover factors influencing delivery performance
* Use advanced Power BI visualizations for deeper analysis

### 📊 Data Sources

The project includes data related to:

* Orders
* Salespersons
* Customers
* Cities

### 🛠️ Files Included

* `Logistics Dashboard.pbix`
* `Database.xlsx`
* Logistics case study documentation
* Project README

# 🚀 Getting Started

To explore the projects locally, clone this repository:

```bash
git clone https://github.com/sasisaidivi/Power_BI_Projects.git
```

Navigate to the repository:

```bash
cd Power_BI_Projects
```

Then:

1. Open **Power BI Desktop**
2. Navigate to the desired project folder
3. Open the `.pbix` file
4. Review or update the data source connections if required
5. Refresh the data
6. Explore the interactive dashboards
